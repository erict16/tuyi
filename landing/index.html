参考

命令行 / CLI

不打开窗口也能译，和桌面版同一条写回。不收费。

tuyi translate

打开 → 提取 → 词库先命中 → 翻译 → 写出新文件

$ python -m tuyi translate drawing.dxf
$ python -m tuyi translate drawing.dwg -o out.dwg --mode zh_to_en
$ python -m tuyi translate a.dxf b.dxf --output-dir out --glossary switch
--mode
zh_to_en（默认）、en_to_zh、zh_to_fr，或 源_to_目标 如 zh-Hans_to_ja
-o / --output-dir
单张写到指定文件；多张用输出文件夹
--glossary
all（默认）、switch 开关、transformer 变压器、off，或你自己的术语 JSON
--provider
deepl / azure / ollama / openai，密钥用桌面版设置里存的
--style
纯译文 / 原译对照 / 译原对照
--translate-filename
文件名里的中文也译

tuyi pdf

把图纸导出成 PDF，译好的或原图都行

$ python -m tuyi pdf out/en_floor_plan.dxf --paper a3l --appearance 彩色
--appearance
Chrome（默认，深色）、彩色（白纸）、黑白
--paper
a4（默认竖向）、a4l、a3、a3l
-o / --output-dir
PDF 写到哪里

在哪跑：源码目录里 python -m tuyi。Windows 安装目录里，tuyi-cli.exe 在 Tuyi.exe 旁边。Mac 在 Tuyi.app/Contents/MacOS/tuyi-cli。

DXF 直接译。DWG 要本机装 ODA File Converter（在 PATH 里，或设 CAD_ODA_EXEC）。

全部参数：python -m tuyi --help · 详见 README

桌面版

想自己看着译？三步

  1. 1

    添加图纸

    点左边加号，或把 DWG / DXF 拖进去。一次可以多张。原文件只读，不改。

  2. 2

    译文字

    词汇库先命中。其余走你自己的 DeepL / Azure / Ollama / 自己配接口。可以手改。

  3. 3

    写出新文件

    点快速翻译就会另存一份。默认在「下载」文件夹，设置里可以换。

只译 DXF，装上就能用。要译 DWG，本机自己装 ODA File Converter。 图译不把它打进安装包。

译的是 CAD 里的字，不是把图当图片扫

标题、注释、属性、标注、表格。中、英、日、韩、德、法等。网上翻译、自己配接口、或不联网。

一批图，一张表，一次写回

常规处理改单张。一起译按队列跑。人工改过的译文可以导出 CSV / Excel，再导入写回。

  • 默认中 → 英，底栏换方向
  • 过滤数字、重复、已经是外文的
  • 导出 PDF：A4 / A3，黑白、彩色或深色
  • 有新版本时，软件里检查更新

常见问题

AI 助手怎么用图译？
让它在终端里跑 python -m tuyi translate 图纸.dxf。没有对话框，不等人点。成功打印新文件路径和句数，失败写到 stderr、退出码不是 0。Claude Code、Cursor、Codex、Grok 这类能跑命令的助手都行。
命令行要密钥吗？
中 ⇄ 英、中 ⇄ 法先走内置词库，命中的不联网。没命中的句子用你在桌面版设置里存的 DeepL / Azure / Ollama / 自定义接口，也可以加 --provider 指定。
Windows 哪个版本能用？
Windows 10 或 11，64 位。32 位不行，Windows 7 / 8 不行。Win10 如果提示缺少 WebView2，装微软的 Edge WebView2 运行时。
我的 Mac 该下哪一份？
左上角苹果 → 关于本机。写着「Apple M1 / M2 / M3 / M4」就下 Apple 芯片。写着 Intel 就下 Intel。两份不能混。Intel 包还没打出来时，按钮会告诉你。
要装 AutoCAD 吗？
不要。图译是独立程序。DXF 直接读；DWG 用你本机的 ODA File Converter。
ODA 打进安装包了吗？
没有，也不会。协议不允许跟软件一起发。你自己装 ODA File Converter。只译 DXF 可以先不装。
第一次打不开？
正常，安装包还没买代码签名。Mac：右键图标，选打开。Windows：更多信息 → 仍要运行。
收费吗？有授权码吗？
不收费，没有授权码。翻译用的密钥是你自己的 DeepL / Azure / Ollama / 自定义接口。图译不建账号，默认也不往外打电话，除非你点检查更新。
