Why it works well for agents

No dialogs, no prompts
Nothing to click and nothing to confirm. It exits when done.
Output that is easy to read
Three lines per drawing: the new file path, the extracted count, and the translated count.
Clear failures
Errors go to stderr with exit code 1; bad arguments exit 2. The assistant knows what failed.
Originals stay put
It always writes a new file and never overwrites the source. Safe to run in bulk.
Glossary first
Chinese ⇄ English and Chinese ⇄ French have built-in glossaries that work offline. Everything else uses the DeepL / Azure / Ollama / custom endpoint saved in settings.
Many drawings at once
Pass several paths with --output-dir. PDF export works the same way.

To translate CAD drawings, use the Tuyi CLI (run it from the Tuyi source folder; the Windows install ships tuyi-cli.exe):
python -m tuyi translate <drawing.dwg or .dxf, several allowed> --output-dir <output folder> --mode zh_to_en
On success it prints the new file path, extracted, and translated for each drawing. On failure read stderr; the exit code is non-zero.
For PDFs: python -m tuyi pdf <translated drawing> --output-dir <output folder>
It never overwrites the source. If unsure about options, run python -m tuyi translate --help first.

Command line / CLI

Translate without opening a window. Same write-back as the app. Free.

tuyi translate

open → extract → glossary first → translate → write a new file

$ python -m tuyi translate drawing.dxf
$ python -m tuyi translate drawing.dwg -o out.dwg --mode zh_to_en
$ python -m tuyi translate a.dxf b.dxf --output-dir out --glossary switch
--mode
zh_to_en (default), en_to_zh, zh_to_fr, or source_to_target such as zh-Hans_to_ja
-o / --output-dir
One drawing to a named file; several to an output folder
--glossary
all (default), switch, transformer, off, or your own terms JSON
--provider
deepl / azure / ollama / openai, using the keys saved in the desktop app settings
--style
纯译文 (translation only) / 原译对照 (source over translation) / 译原对照 (translation over source)
--translate-filename
Translate Chinese in the file name too

tuyi pdf

Export a drawing to PDF, translated or original

$ python -m tuyi pdf out/en_floor_plan.dxf --paper a3l --appearance 彩色
--appearance
Chrome (default, dark), 彩色 (color on white), 黑白 (black and white)
--paper
a4 (default, portrait), a4l, a3, a3l
-o / --output-dir

    Add drawings

    Click the plus on the left, or drop DWG / DXF files. Several at once is fine. The original is read-only.

    Translate

FAQ

How does an AI assistant use Tuyi?
Have it run python -m tuyi translate drawing.dxf in a terminal. No dialogs, no waiting for clicks. Success prints the new file path and line counts; failures go to stderr with a non-zero exit code. Any assistant that can run commands works: Claude Code, Cursor, Codex, Grok.
Does the CLI need an API key?
Chinese ⇄ English and Chinese ⇄ French hit the built-in glossary first, offline. Lines it misses use the DeepL / Azure / Ollama / custom endpoint saved in the desktop app settings, or pick one with --provider.
Which Windows versions work?
Windows 10 or 11, 64-bit. Not 32-bit, not Windows 7 / 8. On Windows 10, install Edge WebView2 if the app asks for it.
Which Mac download do I need?
Apple menu, About This Mac. If it says Apple M1 / M2 / M3 / M4, get Apple silicon. If it says Intel, get Intel. They are not interchangeable. If the Intel build is missing, the button says so.
Do I need AutoCAD?
No. Tuyi is a standalone app. DXF opens directly. DWG uses ODA File Converter on your machine.
Is ODA bundled?
No, and it will not be. The license does not allow shipping it with the app. Install ODA File Converter yourself. DXF-only work does not need it.
It will not open the first time?
That is expected. The installer is not code-signed yet. Mac: right-click the icon, Open. Windows: More info, Run anyway.
Does it cost money? Is there a license key?
No cost, no license key. Translation keys are yours: DeepL, Azure, Ollama, or a custom endpoint. Tuyi does not create accounts. It does not call out unless you check for updates.
